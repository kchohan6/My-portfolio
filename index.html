Credit Card Fraud Detection

Python · Pandas · NumPy · Scikit-Learn
  1. Feature engineering
  2. SMOTE + undersampling
  3. Logistic Regression
  4. Random Forest
  5. GridSearchCV

98%Precision/Recall achieved while keeping false positives low.

  • Engineered features with Pandas and NumPy to surface transaction patterns and improve the model's signal-to-noise ratio.
  • Tackled extreme class imbalance with SMOTE and undersampling to build robust Logistic Regression and Random Forest models.
  • Tuned with GridSearchCV to minimize false positives.

EduSense: AI Focus Tracker

  4. Attention levels

An AI-powered student engagement system that gives educators automated, visual feedback on focus.

  • Monitors real-time attention levels with a Python and Streamlit app.
  • Uses computer vision (OpenCV and MediaPipe) to analyse face and eye movements for behavioural insights.
